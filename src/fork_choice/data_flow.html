Inputs write facts and set dirty; getHead derives the rest

Every handler writes a few flat arrays. No handler updates a weight or a best child. Weights, viability, node status and the head live only in head_cache, rebuilt by head.zig compute on the first getHead after a change.

Layout

Block

A block passes the same checks up to three times, then becomes one new row in every column

Start: rows 0 to 3 hold R, B, C, D. Current slot 35. Block E, slot 35, builds on D's full payload. The caller has its post-state.

Attestation

An attestation becomes one LatestMessage, copied into each attesting validator's entry when it is newer

Start: current slot 36, dirty false. An aggregate for D at slot 35, index 1, from validators 1, 2, 4, 5. Validator 4 is a known equivocator.

Queue

A vote for the current slot waits in queued_messages and lands on the first tick of a later slot

Start: current slot 36. Validator 3 already has a queued vote for slot 36.

Head

getHead rebuilds every node value from the facts, then walks best_child from the justified root

Start: rows 0 to 3 (E not yet imported), current slot 36, justified and finalized R, no boost. Votes: v0 C at slot 34, v1 D full, v2 D empty, v3 B full, v4 equivocating, v5 none.

Payload

A PTC message writes one byte per seat; an envelope writes its own row and validates the payloads under it

Start: rows 0 to 4, current slot 35, E's payload not yet verified, B, C, D and E .syncing.

Optimistic sync

Engine verdicts are written only on the payload rows they name; every node status is derived

Start for both figures: R .valid, B, C, D, E .syncing, root_base_status pre_merge.

Tick and prune

A tick moves time and promotes checkpoints; prune compacts every array in place
